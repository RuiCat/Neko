# 子任务 m2：Go DSH 入口与控制面

## 职责

实现 `cmd/dsh-mcp`：stdio MCP 服务 + 本机 Unix socket 控制面（/health /state /tick /session-event），单实例锁、stale socket 自愈、按日日志、串行化写操作；不复制 tick 体、不直接读 `ent.Data`。

## 输入 / 输出

- 输入: m1 的 `bootstrap.Runtime`、`Server.RunTick`、`Entity.Snapshot`；K1 契约；现有 `mcpserver.New(...).RunStdio`。
- 输出: `cmd/dsh-mcp/main.go`（flag、锁、listener、信号、stdio）；`internal/control`（HTTP-over-UDS handlers、串行器、日志、错误码）；e2e 测试（真实二进制 + 临时 data dir）。

## 契约引用

- 我消费: K5（RunTick/Snapshot）、K6（工具清单）
- 我产出: K1（控制面）、K3（入口与生命周期）
- 契约原文（冻结，不得自行更改）:

  ```text
  K1: HTTP/1.1 over Unix socket，默认 <data-dir>/dsh-control.sock，0600，无 token；
      GET /health；GET /state?entity&path*(可重复)&maxBytes；POST /tick {"scope"}；
      POST /session-event {"kind","sessionId","cwd","turn?","function?"}；
      成功 200 {"ok":true,...}；400 bad_request / 404 not_found / 409 tick_busy /
      405 method_not_allowed / 500 internal（tick Save 失败带 dirty:true）/
      503 shutting_down / 504 deadline_exceeded（服务端 5s）；
      写操作经 WithStateWrite 串行；/tick 用 TryRunTick，拿不到锁立即 409（不排队）；
      与 MCP state_machine_tick 共用 RunTick+tickMu；
      无 transitions/conflicts 的 /tick 不落盘；日志按日 data/logs/dsh-control-YYYYMMDD.log 保留 7 天。
  K3: flags -data-dir/-scripts-dir/-config/-control-socket；stdout 只有 MCP 帧；
      退出码 0/2/3/4；flock data/.engine.lock；stale socket：可连→退出码 3，
      ECONNREFUSED→unlink 重试一次；SIGTERM/SIGINT 清理 socket。
  K5: /session-event 调用 dsh_on_event（若注册）以及其后的 Save 必须包在
      Server.WithStateWrite(func() error) 内，与 MCP tick / entity_state_set 共用 tickMu；
      回调内不得再调用 RunTick 或 WithStateWrite（不可重入）。
  ```

## 边界（不做什么）

- 不改 `internal/mcpserver`、`internal/entity`、`internal/bootstrap`（m1 写域）；需要改就停下报契约缺口。
- 不监听 TCP、不做 TLS、不做多用户鉴权（C13）；不做系统服务安装。
- 不实现 DSH 侧插件（m3）；不写 `dsh/`。
- 不写 `data/`（测试用临时目录）。

## 环境事实（子体必读，父体原样抄进委派 prompt）

- 每次 bash 独立；Go 缓存环境变量：`GOCACHE=$PWD/.local/go-cache GOMODCACHE=$PWD/.local/gomodcache`。
- `/home` 只读、工作区 rw；`~/.dsh` 不可写；不要尝试改 profile。
- Unix socket 仅 Linux/macOS；测试用 `t.TempDir()` 内的 socket 路径（注意 108 字节上限）。
- 不要提权；只写写域；越界发现只报告不处理。
