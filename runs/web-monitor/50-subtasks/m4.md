# 子任务 m4：元件契约与组合树

## 职责

把监视器界面拆成**可独立验收的子元件**（分解表 → `components.json`）并冻结组合关系（`composition.json`）；
不写任何实现。令牌只引用 m2 的语义令牌名。

## 输入 / 输出

- 输入: K4；`design/tokens.json`（m2）；需求节点：实体状态树、实体详情/写表单、诊断列表、脚本列表、日志流、tick 结果、连接状态、全局布局。
- 输出: `design/components.json`（每元件 props/events/slots/states/style/verify/kind）；`design/composition.json`（DAG 组合树，支持 repeat/conditional/slot；每场景一个根）。

## 契约引用

- 我消费: K4；令牌名集合
- 我产出: 元件契约（m5 实现、m6 组合的输入）
- 契约原文（冻结，不得自行更改）:

  ```text
  K4 不变量：任何视觉值有且只有一个令牌名；元件只引用语义令牌，原始色阶只属令牌层；
  组合层只装配、不造原子、不覆盖元件内部样式；分解表每个节点唯一归属、无兜底行；
  组合树 DAG、每场景一个根、repeat/conditional/slot 有显式表达。
  ```

## 边界（不做什么）

- 不写 `design/tokens.json`、`design/dist/**`（m2 写）。
- 不写 `internal/monitor/web/**`（m5/m6 写）。
- 不选框架、不定视觉值、不写实现；元件 `style` 栏只能填语义令牌名。
