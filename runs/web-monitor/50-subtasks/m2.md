# 子任务 m2：设计令牌层

## 职责

为监视器建立视觉值的**唯一来源**：`design/tokens.json`（自描述令牌源）+ 由它生成的 `design/dist/tokens.css`（CSS 自定义属性）。
不写元件、不写页面、不定义布局。

## 输入 / 输出

- 输入: `40-plan.md` K4；现有 `internal/monitor/web/`（若存在，盘点既有颜色/间距）；用户视觉意图（深色/浅色、紧凑/宽松）。
- 输出: `design/tokens.json`（语义令牌为主，含 `tier/type/value/ref/theme/desc`）；`design/dist/tokens.css`（可重建生成物，入库）。

## 契约引用

- 我消费: K4（`40-plan.md`）
- 我产出: 令牌名集合（m4/m5/m6 只能引用这些名字）
- 契约原文（冻结，不得自行更改）:

  ```text
  K4 不变量：任何视觉值有且只有一个令牌名；元件只引用语义令牌，原始色阶只属令牌层；
  design/dist/tokens.css 与 internal/monitor/web/** 生成物入库且可复现（make design 后 git diff --exit-code 为空）。
  ```
