# 子任务 m5：元件实现

## 职责

按 `components.json` 逐元件实现前端源码（原生 HTML/CSS/JS，无框架、无构建链），每个元件一个实现体 + 独立验收；
只依赖元件契约，不依赖其它未完成元件的实现。

## 输入 / 输出

- 输入: K4；`design/components.json`、`design/composition.json`、`design/tokens.json`、`design/dist/tokens.css`。
- 输出: `internal/monitor/web/components/**`（每元件一个目录/文件 + 其 CSS 只引用令牌变量 + 可选 `_verify.sh`）。

## 契约引用

- 我消费: 元件契约与组合树（m4）；令牌（m2）
- 我产出: 元件实现（m6 组合的输入）
- 契约原文（冻结，不得自行更改）:

  ```text
  K4 不变量：元件只引用语义令牌（CSS 变量），禁止硬编码颜色/间距/字号；
  每个元件有独立 verify 且实际跑过；不得依赖其它未完成元件的实现。
  ```

## 边界（不做什么）

- 不写 `design/**`（m2/m4 写）；不写 `internal/monitor/web/index.html`、`app.js`、`app.css`、`wsClient.js`（m6 写）。
- 不做整页组合、不改元件契约、不新增令牌；要新令牌先回 m2。
- 不引入框架/打包器/npm 依赖；不使用行内 style 写具体视觉值。

- 每次 bash 调用是独立环境；持久产物写 `internal/monitor/web/components/`；多步验证放同一次调用。
- 项目无 `.agent-memory/`：跳过记忆读协议，不中断任务。
- 只写 `internal/monitor/web/components/`；其余只读。
- 不要请求提权；不要联网；不要安装依赖。

- 命令: `bash ~/.dsh/skills/ui-composition/scripts/lint-ui-plan.sh --plan-dir design --tokens design/tokens.json --src-root internal/monitor/web`
