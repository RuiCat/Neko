# 容器 / 器官 / 躯体 底层内核设计

> 状态：v1 设计稿（2026-11-16）。**仅设计底层**，不涉及事件、台词、LLM、动画。
> 本文档汇总多轮设计讨论的结论；所有数值为设定值（游戏近似量级），实现前可调。
> 关联文档：`docs/scripts-layers.md`（层号）、`docs/material-layer.md`（素材/交互）、`docs/base-data-definition.md`（字段所有权）。

---

## 0. 文档定位

| 项 | 内容 |
|---|---|
| 解决什么 | 器官/物品统一的「容器关系 + 器官性状 + 结构关联 + 内容追踪」底层 |
| 不解决什么 | 事件编排、台词选择、LLM 生成、渲染/动画、数值平衡定稿 |
| 受众 | 引擎脚本实现者、数值调参、内容分层审查 |
| 前置结论 | 无坐标（只保留 1D 进入深度）；容器=关系、器官=实体数据；派生字段由函数唯一写入、全局可读 |

---

## 1. 设计原则

1. **容器只描述关系**：器官与哪些器官相连、能否插入、能否流入/流出、是否密封。容器不持有任何实体数值。
2. **器官持有实体数据**：尺寸、扩张度、敏感度、内容、应力、破口、面状态全部在 `器官内核`。
3. **部件只描述结构**：谁挂在谁身上、关节类型。尺寸/敏感度/损伤不在部件上。
4. **物品同构**：物品的实体数据放 `器皿性状`，关系仍走 `容器`。
5. **一个字段一个写入者**：派生字段由函数写入，只写一次；写入后全局可读。
6. **指向优先**：生理（完整性/功能/灌注/应力）、体温、属性（体质/敏捷/意志）、伤害、衣物遮挡一律读现有所有者，不复制。
7. **无坐标**：不存体表 X/Y/Z、不存关节角度；唯一的一维量是「进入深度」（mm，沿腔道的弧长），它不是空间坐标。
8. **多来源数值必须拆字段**：引擎一个字段只能绑一个 `@事件`（`internal/entity/schema.go:82-83`），多事件绑定 = 每个来源一个修正字段 + 一个派生总值。

---

## 2. 结构总览

```text
器官内核（实体数据，唯一真值）
├─ 器官.<名>          完整性 / 功能 / 灌注 / 应力        （已有，不动）
└─ 器官性状.<名>      尺寸 / 扩张度 / 敏感度 / 内容 /
                      面状态 / 插入应力 / 破口          （新增）

容器.<名>             器官关联关系（上游/下游/可插入/可流入/可流出/密封/连接类型）
部件.<名>             结构关联（父/子/类型/关节）
器皿性状              物品的容量/内容/温度/材质（挂 素材）
```

职责一句话：**容器说“关系”，器官说“实体”，部件说“结构”，器皿说“物品实体”。**

### 3.2 字段语义

| 字段 | 语义 | 写入者 |
|---|---|---|
| 长度/静息直径/最大直径/壁厚/弹性/静息容量 | 静态尺寸参数 | 数据 |
| 扩张度 | 当前扩张程度（0=静息，100=最大直径） | 性反应内核（6000） |
| 对象直径 | 本次插入物的直径（输入） | 插入动作规则 |
| 进入深度 | 沿腔道的弧长（mm，不是坐标） | 插入动作规则 |
| 敏感度基础 | 部位固有敏感度 | 数据 |
| 敏感度修正.<源>.值 | 各来源的修正量 | 各来源规则/事件 |
| 敏感度修正.<源>.剩余 | 过期倒计时（分钟；-1=永久） | 3020 段递减 |
| 敏感度 | 派生：`clamp(基础+Σ有效修正,0,100)` | 派生函数（3020） |
| 容量 | 派生：`静息容量 × (1 + 弹性/100 × 扩张度/100)` | 派生函数（3020） |
| 当前直径 | 派生：`静息 + (最大−静息) × 扩张度/100` | 派生函数（3020） |
| 内容 | 动态列表：`[{物质,量,温度,来源,时间}]` | 容器/交互追加 |
| 内容量 | 派生：`Σ 内容[].量` | 派生函数（3020） |
| 吸收率/蠕动 | 器官行为参数 | 数据 |
| 泄漏量 | 壁破口后漏出的量（中转给 L3） | 3020 段 |
| 插入应力/破口 | 被动撑开的中间结果 | 3020 段撑开函数 |
| 面状态 | 两面朝向/暴露/接触/可见 | 外翻/脱垂/接触规则 |

### 3.3 面状态

每个器官的壁有两个面：**内腔面**（黏膜面）与**外表面**（浆膜面）。面状态是显式状态，不是从几何推导：

| 字段 | 取值 | 说明 |
|---|---|---|
| 朝向 | 腔内 / 体腔 / 体外 | 这一面朝向哪里 |
| 暴露 | true/false | 是否暴露在体外（可被看到/接触） |
| 接触 | 空 / 手指 / 素材 id / NPC id | 当前接触对象 |
| 可见 | true/false | 是否可被观察（配合衣物遮挡） |

- 正常：内腔面朝腔内、外表面朝体腔，两者暴露=false。
- 外翻：翻转段的内腔面 → 朝体外、暴露=true；外表面 → 朝翻转腔；`容器.可插入` 改指翻转腔，暴露面本身不再可插入。
- **湿润度不放进面状态**：沿用 `器官状态.基础生理.湿润度`（`internal/engine/effects.go:58-64` 的效果别名目标），避免第二套真值。

### 3.5 敏感度：多来源 + 过期

**为什么必须拆字段**：引擎一个字段只能绑一个 `@事件`（`internal/entity/schema.go:82-83`，后者覆盖前者），事件处理器只拿得到 `新值/旧值/变化量`、拿不到来源（`scripts/kernel/events/eventsHooks.neko`）。因此“多事件绑定”的唯一可行形态是：

```
敏感度 = clamp(敏感度基础 + Σ(各来源修正.值), 0, 100)   // 派生只读
```

| 来源 | 谁写 | 过期 | 事件绑定 |
|---|---|---|---|
| 训练 | 训练/经验规则 | 永久（剩余=-1） | `@事件敏感度训练` |
| 药物 | 物品/药物规则 | 分钟倒计时 | `@事件敏感度药物` |
| 伤害 | L3 伤害结算 | 分钟倒计时 | `@事件敏感度伤害` |
| 周期 | 生殖周期规则 | 永久/按相位 | `@事件敏感度周期` |
| 性反应 | 性反应内核 | 短时（如 30 分钟） | `@事件敏感度性反应` |

`剩余` 语义：`-1` = 永久；`>0` = 分钟倒计时；归零时该来源 `值=0`。

### 3.6 内容（动态列表）

```json
[{"物质":"水","量":200,"温度":220,"来源":"口","时间":0}]
```

- `物质` 是开放字符串：水/食物/精液/爱液/尿/血/药/酒。
- `量` 单位 mL；食物热量走物质表的 `热量密度(kcal/mL)`，不塞进条目。
- `时间` 是进入容器的 tick/分钟，用于吸收、变质、残留结算。
- 追加：`$.器官性状.胃.内容 += {"物质":"水","量":200,"温度":220,"来源":"口","时间":0}`
- 元素级增删改查只能走 `@函数`（规则不能动态寻址列表元素）。

## 4. 容器（关系）

> 命名注意：`容器` 作为**字段组**（关系）与现有素材模板 `容器`（`@实体 容器 [素材, 容器内核]`，`scripts/kernel/material/materialModel.neko:87`）处于不同命名空间。落地时素材模板 `容器` 改挂 `器皿性状`，原 `容器内核` 模板退役；字段组 `容器` 保留，避免迁移期出现 `素材.容器` 双重语义。

```neko
"容器": {
  "口":   {"上游":"",     "下游":"食道", "可插入":true,  "可流入":true,  "可流出":true,  "连接类型":"孔",   "密封":false},
  "食道": {"上游":"口",   "下游":"胃",   "可插入":true,  "可流入":true,  "可流出":true,  "连接类型":"管腔", "密封":false},
  "胃":   {"上游":"食道", "下游":"肠道", "可插入":false, "可流入":true,  "可流出":true,  "连接类型":"囊",   "密封":true},
  "肠道": {"上游":"胃",   "下游":"直肠", "可插入":false, "可流入":true,  "可流出":true,  "连接类型":"管腔", "密封":true},
  "阴道": {"上游":"",     "下游":"宫颈", "可插入":true,  "可流入":true,  "可流出":true,  "连接类型":"黏膜", "密封":false},
  "宫颈": {"上游":"阴道", "下游":"子宫", "可插入":true,  "可流入":true,  "可流出":true,  "连接类型":"管腔", "密封":false},
  "子宫": {"上游":"宫颈", "下游":"输卵管","可插入":true, "可流入":true,  "可流出":true,  "连接类型":"腔",   "密封":false},
  "输卵管":{"上游":"子宫","下游":"腹腔", "可插入":true, "可流入":true,  "可流出":true,  "连接类型":"管腔", "密封":false}
}
```

| 字段 | 语义 |
|---|---|
| 上游/下游 | 链路连通关系（位置追踪只靠它，不需要坐标） |
| 可插入 | 该器官是否接受插入（性反应/交互的门槛） |
| 可流入/可流出 | 内容能否进出（胃能流入不能插入） |
| 连接类型 | 孔/管腔/囊/腔/黏膜（给台词与损伤用） |
| 密封 | 物品容器的关系（杯子密封 vs 漏） |

> 这些是**名义拓扑**，保持静态。外翻/还原不改它们，有效上游/下游/可插入由 §11 的派生函数按 `翻出点` 计算。

## 5. 部件（结构关联）

```neko
"部件": {
  "躯干":   {"父":"",      "子":["颈","左上臂","左大腿"], "类型":"根",   "关节":"固定"},
  "颈":     {"父":"躯干",  "子":["头"],                  "类型":"肢段", "关节":"球窝"},
  "头":     {"父":"颈",    "子":["脸","左耳","右耳"],     "类型":"末端", "关节":"固定"},
  "左上臂": {"父":"躯干",  "子":["左前臂"],              "类型":"肢段", "关节":"球窝"},
  "左前臂": {"父":"左上臂","子":["左手"],                "类型":"肢段", "关节":"铰链"},
  "左手":   {"父":"左前臂","子":[],                      "类型":"末端", "关节":"球窝"}
}
```

- 部件只存 `父/子/类型/关节`，**不存坐标、不存角度、不存尺寸、不存敏感度**。
- 尺寸/敏感度在 `器官性状`；损伤状态在 `器官.<名>`（L3 写）。
- 断肢：`器官.<名>.功能=0/完整性=0` + 部件关系清空 + 生成掉落素材；不删节点，保留历史。

## 7. 派生函数与写权

| 派生字段 | 函数 | 公式 |
|---|---|---|
| 敏感度 | `敏感度合成()` | `clamp(基础 + Σ(剩余≠0 的修正值), 0, 100)` |
| 容量 | `器官容量()` | `静息容量 × (1 + 弹性/100 × 扩张度/100)` |
| 当前直径 | `器官直径()` | `静息 + (最大−静息) × 扩张度/100` |
| 内容量 | `器官内容量()` | `Σ 内容[].量` |
| 插入应力 | `撑开应力()` | 见第 9 节 |
| 破口 | `撑开破口()` | 见第 9 节 |

**写权总表**

| 数据 | 位置 | 写入者 |
|---|---|---|
| 静态尺寸/参数 | 器官性状 | 数据 |
| 扩张度 | 器官性状 | 性反应内核（6000） |
| 对象直径/进入深度 | 器官性状 | 插入动作规则 |
| 敏感度修正.<源> | 器官性状 | 各来源规则/事件 |
| 敏感度/容量/当前直径/内容量 | 器官性状 | 派生函数（3020） |
| 内容 | 器官性状 / 器皿性状 | 容器/交互追加 |
| 插入应力/破口/泄漏量 | 器官性状 | 撑开函数（3020） |
| 完整性/功能/灌注/应力 | 器官.<名> | L2/L3 |
| 上游/下游/可插入/面状态 | 容器 / 器官性状 | 外翻/脱垂规则 |
| 父/子/关节 | 部件 | 数据/伤害 |
| 容量/内容/温度 | 器皿性状 | 交互 |

**规则**：派生字段全局可读、但不允许规则写；函数是唯一写入者。

## 8. Tick 分配

| 优先级 | 层 | 做什么 | 写什么 |
|---|---|---|---|
| 3000–3010 | L2 器官 | 完整性结算（已有） | `器官.<名>.*` |
| **3020** | L2 器官性状 | 修正过期 → 派生重算 → 撑开应力/破口 → 吸收/泄漏 | `器官性状.*` |
| 3990–4008 | L3 路径/伤害 | 读 `插入应力/破口/泄漏量` → 应力/污染/伤害 | `路径.*`、`伤害.*` |
| 6000 | L4.5 性反应 | 写 `扩张度`、`敏感度修正.性反应` | `器官性状.*` |

**已知取舍：1 tick 延迟。** 性反应（6000）写的 `扩张度` 要下一 tick 的 3020 才被派生采用；吸收输出由 3020 写入、代谢（1000）下一 tick 读取。好处是每个派生字段只有一个写入点，唯一性不破。

## 9. 撑开 / 破裂 / 损伤链

```neko
@函数 撑开应力(对象直径:int, 当前直径:int, 最大直径:int) -> int {
  if 对象直径 <= 当前直径 { 返回 0 }
  上限 = max(最大直径, 1)
  返回 int(min(100, (对象直径 - 当前直径) * 100 / max(上限 - 当前直径, 1)))
}

@函数 撑开破口(对象直径:int, 最大直径:int, 完整性:int) -> bool {
  if 对象直径 <= 最大直径 { 返回 false }
  返回 完整性 <= 100 - (对象直径 - 最大直径) * 2
}
```

链路：

```
插入动作 → 器官性状.对象直径
3020 段  → 插入应力 / 破口 / 泄漏量
3990 段  → 路径.应力 → 器官.<名>.完整性 / 伤害.出血 / 路径.污染
```

- 器官/容器都不直接写伤害，结算归 L3。
- 破口后内容按 `泄漏量` 漏出，写入 `泄漏量` 由 3020 段计算，L3 读。

## 10. 内容追踪

| 结算 | 规则 | 说明 |
|---|---|---|
| 传输 | `容器.上游 → 容器.下游`（可流出 ∧ 可流入 ∧ 蠕动/重力） | 每条链一对规则，显式 |
| 吸收 | `吸收率 × 流逝分钟` → 写 `器官性状.<名>.吸收输出`（能量/液体） | 代谢下一 tick 读 |
| 溢出 | `内容量 > 容量` → 溢出到上游/环境 | 呕吐、灌满、倒酒 |
| 泄漏 | 破口 ∧ 内容量>0 → `泄漏量` | 接 L3 污染/感染 |
| 温度 | 内容条目温度 → 器官/器皿温度 | 收敛到体温或环境温 |
| 变质 | `时间` + 物质表保质期 | 食物腐败 |

## 11. 外翻拓扑（重新设计）

### 11.0 旧模型的问题与本次原则

旧模型不能照抄：`cat_eversion_process.neko` 的 E3 说“子宫内膜外露”、E4 说“浆膜面成为外表面”，两句话互相矛盾；0–6 层级只是计数器，没有描述入口与面；`状态操作: [6,6,1]` 是序列化位置，无法恢复语义。

**本次原则**：
1. 单一状态源 = `翻出点`（器官名）。层级、翻转段、入口、可插入全部由它派生，不存重复状态；
2. 名义拓扑（`容器.上游/下游/可插入`）保持静态，**有效拓扑由函数派生**，这样还原天然可逆；
3. 面状态是唯一需要显式写回的状态（`器官性状.<名>.面状态`）；
4. 逐级推进、禁止跳级；还原逐级回退。

### 11.1 链路与端口

```text
生殖道链：阴道 → 宫颈 → 子宫 → 输卵管 → 卵巢（实质器官）
每个容器两个端口：近端（朝外）/ 远端（朝内）
正常拓扑：体外 = 阴道.近端；输卵管.远端 → 腹腔
面：内腔面 A（黏膜）/ 外表面 B（浆膜）；实质器官（卵巢）只有被膜面 B
```

### 11.2 变换规则（翻出点 = k）

| 量 | 变换 |
|---|---|
| 翻转段 | 从 k 到链尾（或到 `翻出点` 允许的最大段）的连续容器集合 |
| 面 A | 朝体外、暴露=true |
| 面 B | 朝翻转腔（新的穿行面） |
| 端口 | 翻转段远端→近端反转，入口改为 k 的近端 |
| 可插入 | 指向翻转腔（B 侧）；暴露的 A 面不可插入 |
| 盲端 | 翻转段远端的 B 侧腔底 |
| 内容 | 守恒：留在各自 `器官性状.<名>.内容`，只改可达性 |
| 支撑 | 翻转段每级扣减支撑（韧带/固定），低于门槛时产生损伤 |

| 层级 | 翻出点 | 翻转段 | 入口 | 穿行面 | 暴露面 | 可插入 | 盲端 | 支撑门槛 | 伤害风险 |
|---|---|---|---|---|---|---|---|---|---|
| E0 | — | — | 阴道口 | 内腔面 | — | 阴道 | 阴道穹窿 | — | — |
| E1 | 阴道 | 阴道 | 阴道口内翻环 | 阴道外表面 | 阴道内腔面 | 翻转腔 | 阴道穹窿 | 60 | 阴道黏膜撕裂/出血 |
| E2 | 宫颈 | 阴道+宫颈 | 宫颈环 | 宫颈外表面 | 宫颈内腔面 | 翻转腔 | 宫颈管底 | 55 | 宫颈裂伤、出血 |
| E3 | 子宫 | 阴道+宫颈+子宫 | 宫颈环 | 子宫外表面 | 子宫内膜 | 翻转腔 | 宫底 | 45 | 子宫内翻、休克风险 |

### 11.4 旧 E1–E6 映射

| 旧层级 | 旧语义 | 新层级 | 说明 |
|---|---|---|---|
| E1 | 阴道内壁外翻 | E1 | 一致 |
| E2 | 宫颈外翻 | E2 | 一致 |

| E4 | 完全子宫（浆膜面外露） | E3 | **合并**：旧 E4 的“浆膜面外表面”按新模型是翻转腔 B 侧，不再单列 |
| E5 | 输卵管外翻 | E4 | 顺延 |
| E6 | 卵巢脱出 | E5 | 顺延 |

### 11.5 还原（reduction）

- 逐级逆序：E5→E4→E3→E2→E1→E0，每级一次动作或一次结算；禁止跳级。
- **可完全还原**：翻转段 `器官.<名>.完整性 = 100` ∧ `破口 = false` ∧ `支撑 ≥ 门槛`。
- **不完全还原**：保留后遗症（支撑上限下降、粘连标记），`翻出点` 可归零但 `后遗症 = true`；后遗症是不可逆状态，写入 `器官性状.<名>.后遗症`。
- 还原不重置内容（内容守恒），但破口泄漏过的量已计入 `泄漏量`，不补回。

### 11.6 可逆性测试用例

| 用例 | 步骤 | 期望 | 断言 |
|---|---|---|---|
| T1 逐级正翻 | E0→E1→…→E5 | 每级成功 | `翻出点` 逐级推进；翻转段 `内腔面.暴露=true`；`有效可插入` 指向翻转腔 |
| T2 逐级还原 | E5→…→E1→E0 | 全部成功 | `翻出点=""`；所有面状态回到正常；`有效上游/下游/可插入` = 名义值；内容守恒 |
| T3 跳级拒绝 | E0→E3 | 拒绝 | `翻出点` 不变；`结果="拒绝：禁止跳级"` |
| T4 支撑不足 | 支撑=30 时执行 E3 | 推进但损伤 | 翻出点推进；`器官.<名>.完整性 < 100`；`后遗症=true` |
| T5 内容守恒 | 翻转前后读 Σ内容量 | 相等 | 若破口：差额 = `泄漏量` |
| T6 连通性 | 从入口沿 `有效下游` 遍历 | 集合 = 翻转段 ∪ 其后的可达段 | 不出现未翻转段被错误连通 |
| T7 盲端 | 沿 `有效下游` 从入口走到底 | 停在翻转段远端 | 未翻转段的容器不可达 |
| T8 暴露面不可插入 | 读 `可插入(暴露面)` | false | `可插入(翻转腔)` = true |
| T9 有损伤还原 | E3 制造破口后还原 | 部分还原 | `翻出点=""`，`后遗症=true`，`支撑上限 < 100` |
| T10 旧映射 | 旧 E4 存档载入 | 等价新 E3 | 翻转段 = 阴道+宫颈+子宫 |

**断言写法（示意）**：

```text
初始：翻出点=""，面状态.阴道.内腔面.朝向="腔内"
执行：动作 外翻 → 翻出点="阴道"
断言：器官性状.阴道.面状态.内腔面.暴露 = true
断言：有效可插入("阴道") = "翻转腔"
断言：有效下游("阴道") = "宫颈"（名义不变，方向由函数解释）
```

## 13. 引擎约束与待验证

**已核实**

- 一个字段只能绑一个 `@事件`（`internal/entity/schema.go:82-83`）；
- `+=` 右侧为 JSON 容器时转 `append`（`internal/neko/parserRule.go:120-135`）；`-=` 不能删列表元素；`append` 不 extend（`internal/engine/ops.go:79-110`）；
- 函数可持实体 ID 局部变量、动态查实体、跨实体写回、读 map（`internal/function/entityAccess.go:11-68`）；
- 多主体规则头用全角逗号（`internal/neko/parserRule.go:71`）；
- 层号：器官 3000–3010、路径 3990–4008，3020–3989 可用；
- 函数实参支持 `$.路径`：`resolveCallArgument` 对非字面量走 `resolver(base)`（`internal/engine/funcCall.go:163-193`）；
- `映射.get(变量键)` 可用：`methodGet` 接收运行时参数（`internal/function/methods.go:46-47`）；
- 多主体同模板双实体：按选择器笛卡尔积绑定，**同一实体不可重复绑定**（`internal/engine/engine.go:287-320` 的 `seen` 检查），两个不同容器实体可以配对；受 `MAX_RULE_EVAL`/`MAX_TRANSITIONS` 上限约束；
- 规则动作值**不支持「路径/常数」算术表达式**（如 `$2.食物.中毒风险 / 2`），会被当字符串写入；算术必须收进 `@函数`，规则只做 `字段 = 函数(...)`。

**待验证**

| 项 | 验证方式 | 影响 |
|---|---|---|
| 派生字段“只读”无引擎强制 | 现状只能靠约定 + lint | 写入纪律 |
| 容器×容器笛卡尔积在实体数量上升后的规模 | 压力测试 | 传输规则性能 |
| 外翻派生函数需要的链路常量表（`@data 腔道链`） | 先定数据形状，再实现 `有效上游/有效下游/可插入` | 外翻规则实现方式 |
| 11.6 测试用例的执行载体（probe / replay） | 选出可复算的一条命令 | 验收方式 |

### 边界修正（2026-11-16）

- **卵巢**：加入 `器官性状`（长度/周长/敏感度基础/敏感度修正/敏感度/被膜面面状态）；外翻 E5 写回被膜面（朝向=体外、暴露=true），还原 E4 时恢复；补 E5 支撑损伤规则（门槛 25）。
- **泄漏**：破口不再一次清空内容，改为每次漏出 50%（`泄漏量下一步`），3025 段用 `内容保留(内容,50)`；溢出仍按超容量裁剪。
- **敏感度事件**：五个来源的 `值` 字段加 `@事件敏感度<来源>`，新增 `organTraitEvents.neko`（5 个处理器写 `状态.触发`，条件 `变化量 != 0`）。
- **吸收接线实测**（`.local/probe12`）：能量储备 +299（设 吸收输出能量 300）、体液 +500（设 吸收输出液体 500），证明 990/1190 两段确实消费 3020 的吸收输出。
- **事件实测**：设 `敏感度修正.训练.值=10` → `状态.触发 = 敏感度变化:训练`，`敏感度 = 70`。

### 剩余边界（未在本轮解决）

- `@事件` 处理器只写 `状态.触发`，暂无外部订阅方消费这些事件；
- 吸收消费的是上一 tick 的吸收输出（1 tick 延迟，与既有“吃→下个 tick 吸收”一致）；
- 容器间传输是逐对显式规则（未做通用“容器对容器”规则）；
- 运行中的实例仍需重置派生数据（`templates/`、`scripts.json`）后重启；
- 跨盘备份未完成（目标盘 `ntfs3` 只读、`sudo` 不可用）。

### 已发现并修复的既有缺陷

- `interactRules.neko` 的 `ixEat` 原本用 `$1.伤害.感染 += $2.食物.中毒风险 / 2`（动作值里做算术）。引擎不会求值这种「路径/常数」表达式，会把表达式文本写入字段；进食后 `伤害.感染` 变成字符串，进而 `代谢.体温` 等函数报「string - int64」，体温字段被写成函数调用文本，级联破坏体液/渗透压/血钠。
  修复：新增 `感染摄入下一步`/`疼痛摄入下一步`（`injuryFunctions.neko`），规则只做函数赋值。验证：`.local/probe6` 进食后 `代谢.体温 = 368`、`伤害.感染` 保持数值。
