# scripts/ 脚本源目录

`.neko` 源文件按职责归档；注册名 = 文件名去掉 `.neko`（跨目录不得重名）。启动时注册表缺失会递归扫描本目录并引导注册。

| 目录 | 内容 |
|---|---|
| `core/` | 实体模型/身体/器官/状态同步等核心定义 |
| `behavior/` | 日常行为、情绪、关系、任务、场景交互 |
| `auto/` | 自动生成/填充脚本（`cat_auto_*`、`cat_fill_*`） |
| `r18/` | R18 行为与规则 |
| `rules/` | 独立规则脚本（`rule_*`） |
| `scene/` | 场景资产/移动 |
| `meta/` | 安全、日志、自检、脚本治理 |
| `derivations/` | 衍生规则（运行期产物，保留） |
| `repairs/` | 事件修复脚本（运行期产物，保留） |

`rules.json`（可选）与脚本同级，启动时由 engine 加载。
